# Personal Portfolio Website  
A fully static, component‑based portfolio created as part of my Bachelor of Information Technology coursework at NMIT. This project demonstrates my ability to design, structure, and build a clean, responsive website using only HTML and CSS, following professional front‑end development practices.

---

## Project Purpose  
This portfolio was developed to showcase my academic projects, technical skills, and contact information in a simple, accessible, and visually organised format. The website is intentionally static, meaning it does not use JavaScript, backend processing, or dynamic content. All pages are built using pure HTML and CSS, and navigation is handled through separate HTML files instead of jump links, as required by the assignment.

The project also serves as a demonstration of my understanding of component‑based design, folder organisation, responsive layouts, and GitHub Pages hosting.

---

## Folder Structure  
The project follows a modular, component‑based structure to keep the code organised and easy to maintain.


This structure ensures that each part of the website is separated into logical components, making the project easier to understand and maintain.

---

## Hosting with GitHub Pages  
The portfolio is hosted using **GitHub Pages**, which allows static websites to be published directly from a repository.

### Steps to enable GitHub Pages:
1. Open the repository on GitHub.  
2. Go to **Settings**.  
3. Scroll down to **Pages**.  
4. Under **Source**, select:  
   - **Deploy from a branch**  
5. Choose branch:  
   - **main**  
6. Choose folder:  
   - **root**  
7. Save the settings.

GitHub Pages will generate a public link where the portfolio becomes accessible online.

## Components  
The website uses a component‑based approach:

### **Header Component**
- Contains the navigation bar.
- Included manually on every page.
- Styled using `header.css`.

### **Footer Component**
- Simple footer displayed on all pages.
- Styled using `footer.css`.

### **Home Component**
- Hero section with name, biography, and profile image.
- Styled using `home.css`.

### **Projects Component**
- Grid layout displaying project cards.
- Styled using `projects.css`.

### **Skills Component**
- Two‑column layout for technical and soft skills.
- Styled using `skills.css`.

### **Contact Component**
- Static contact form with name, email, and message fields.
- Styled using `contact.css`.
